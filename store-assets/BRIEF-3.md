## Как выглядят топовые приложения сейчас (Structured, Opal, Duolingo в App Store)

- Заголовок **по центру** сверху, 2-3 строки, крупно. Приём: одна строка обычным весом (Onest Regular),
  ключевые слова жирным (Onest Bold). Например: "Расписание" (regular) / "твоей группы" (bold).
  Подзаголовок не обязателен; если есть - одна короткая строка.
- **Один iPhone по центру, прямо, без наклона**, ширина корпуса 76-84% ширины кадра. Верх телефона
  сразу под заголовком, низ уходит за нижний край кадра (видно примерно 70-80% телефона).
- Фон: сплошной цвет или мягкий градиент бренда, без панорамных лент, без тёмного космоса.
- В 1-2 кадрах деталь интерфейса "выходит" из телефона: увеличенная карточка с тенью,
  наполовину за пределами корпуса (у нас это кольцо 92% и строки оценок 5/5, 3/5).
- Серия цельная: одинаковые позиция заголовка, размер телефона, отступы.

## Фон и цвета

Насыщенный фиолетовый бренда: градиент сверху вниз `#7B6CF0` -> `#4B3FBF`, лёгкое радиальное
свечение `#C3B6FF` за телефоном (opacity 0.25-0.35). Текст белый. Ни белого, ни чёрного фона:
он сливается со светлой/тёмной темой App Store.
Кадр 1 можно сделать темнее (`#2A2170` -> `#120E2E`), чтобы стеклянный медведь светился.

## iPhone (iPhone 17 Pro Max, чистый CSS, без картинок-рамок)

Скриншоты 1320x2868 - это родное разрешение экрана iPhone 17 Pro Max, поэтому экран = скриншот
1:1 по пропорциям, ничего не обрезать и не растягивать.

- Экран: `<img>` с `border-radius` около 13.5% ширины экрана (углы iOS).
- Чёрная рамка (bezel) вокруг экрана: около 1.7% ширины экрана, цвет `#050505`.
- Корпус-металл снаружи рамки: 0.7-0.9% ширины, тёмный титан - linear-gradient из
  `#3a3a3f`, `#8e8e93` (блик), `#2c2c30`, плюс тонкий светлый inner highlight по краю.
  Радиус корпуса = радиус экрана + толщина рамки + толщина металла.
- Dynamic Island: чёрная пилюля `#000` по центру сверху поверх экрана, ширина ~28.5% ширины экрана,
  высота ~2.9% высоты экрана, отступ сверху ~1.25% высоты экрана, полностью скруглённая.
  Должна стоять между временем 09:41 и значками справа, ничего не перекрывая.
- Боковые кнопки: слева Action button (короткая) и две кнопки громкости, справа кнопка питания
  и Camera Control (плоская, ниже питания). Тот же металл, выступают на 0.5-0.6% ширины.
- Тень под телефоном: большая мягкая (например `0 60px 120px rgba(20,10,60,.45)`).

Сделай один компонент `.iphone` в `shared.css`, все 6 кадров используют его.

## Кадры

1. Медведь (вырезка из `01-welcome`, мягкая маска без видимых краёв) крупно по центру. Снизу
   выглядывает верхняя треть iPhone с экраном `15-schedule-week-light`.
   Заголовок: "Весь колледж" (bold) / "в одном приложении" (regular).
2. `15-schedule-week-light`: "Расписание" / "твоей группы". Подзаголовок: "Работает без входа".
3. `24-attendance-dark`: "Посещаемость" / "под контролем". Выноска: кольцо 92% выходит за правый край корпуса.
4. `11-scores-sheet-light`: "Все баллы" / "по каждому предмету". Выноска: строки 5/5 и 3/5 выходят за левый край.
5. `07-leaderboard-light`: "Стрик" / "и рейтинг курса".
6. `26-schedule-week-black`: "Тёмная тема" / "для OLED-экранов". Один iPhone, без второго телефона.

Длинные тире, ёлочки и типографские кавычки не использовать.

## Проверка

Открой каждое превью и проверь: Dynamic Island не перекрывает время и значки, углы экрана
совпадают с рамкой (нет светлых щелей), заголовок не налезает на телефон, на превью шириной
~230 px заголовок читается. Обнови `out/README.md`.
