# Бриф: графика для магазинов приложений МойКЦТ

Работай только внутри этой папки (`store-assets/`). Ничего вне неё не меняй.

## Продукт

МойКЦТ - приложение студентов Колледжа Цифровых Технологий (Россия): расписание группы,
посещаемость, баллы по предметам, стрик и рейтинг курса. Расписание работает без входа,
посещаемость и баллы - после входа корпоративным логином. Аудитория - студенты 15-20 лет.
Талисман - стеклянный полигональный медведь в фиолетовых VR-очках (на `src/01-welcome.png`).

## Бренд

- Шрифт: Onest (`fonts/onest_regular|semibold|bold.ttf`), подключать через `@font-face`.
- Акцент `#6C5CE7`. Градиент акцента: `#C3B6FF` 0%, `#9B8CFF` 12%, `#6C5CE7` 40%, `#4B3FBF` 100%.
- Доп. фиолетовые: `#A347E0` (маджента), `#4A54C9` (индиго), `#E8E5FF` (светлая заливка).
- Фоны: тёмный `#0C0C11`, светлый `#F4F4F8`, OLED - чистый чёрный.
- Огонёк стрика оранжевый, оценки: зелёный/жёлтый/красный.

**Скриншоты интерфейса вставлять пиксель в пиксель.** Не перерисовывать UI, не генерировать
его заново нейросетью, не менять текст внутри скриншотов. Генерацию изображений можно
использовать только для фона и декора (стеклянные ленты, свечение, абстрактные формы
в стиле арта медведя), без текста и без интерфейсов. Медведя можно вырезать из
`src/01-welcome.png` (верхняя часть, примерно y 150-1250 в исходнике).

## Тренды 2026 (по Dribbble/Behance и ASO-гайдам)

- Тёмная высококонтрастная палитра с одним ярким акцентом; светлые экраны на тёмном фоне читаются лучше всего.
- Крупный жирный заголовок-выгода сверху (2-4 слова), подзаголовок мельче. Текст должен читаться на превью шириной ~200 px.
- Большой реальный UI: телефон крупно, допускается обрезка телефона краем кадра, лёгкий наклон или два телефона внахлёст.
- Панорамный фон: одно широкое полотно, нарезанное на все скриншоты, чтобы лента в магазине выглядела цельной историей.
- Стекло (glassmorphism), мягкое фиолетовое свечение, крупные выноски-"чипы" с вырезанной деталью UI (например кольцо 92% или оценка 5/5), увеличенные поверх телефона.
- Без кнопок "Скачать", значков магазинов, "#1", "лучшее", выдуманных функций.

## Что сделать

### 1. Скриншоты для RuStore и Google Play: 6 штук, 1080x1920 (9:16), PNG без альфы, < 5 МБ

Рамка телефона - нейтральная современная (скруглённый корпус, тонкая рамка), без логотипов брендов.
Порядок и заголовки (можно улучшить формулировки, смысл сохранить, без длинных тире и ёлочек):

1. `01-welcome` - "Весь колледж в одном приложении" / "Расписание, посещаемость и баллы". Медведь как герой кадра.
2. `15-schedule` - "Расписание твоей группы" / "Работает без входа".
3. `24-attendance` - "Посещаемость под контролем" / "Календарь месяца и процент пар". Выноска: кольцо 92%.
4. `11-scores` - "Все баллы по предметам" / "Оценки по каждому занятию". Выноска: строки 5/5, 3/5.
5. `07-leaderboard` - "Стрик и рейтинг курса" / "Ходи на пары и поднимайся в топ".
6. `26-black` - "Тёмная тема для OLED" / "Светлая, тёмная и чёрная". Покажи два телефона внахлёст: `15` (светлая) и `26` (чёрная).

Все 6 - единая серия: один фон-панорама, одна сетка, один размер заголовков.
Имена: `out/screens/01.png` ... `out/screens/06.png`.

### 2. Google Play feature graphic: `out/google-play-feature-1024x500.png`

1024x500, PNG 24-бит без альфы. Ключевое - по центру (края режутся). Фон не чисто белый/чёрный.
Медведь + 1-2 телефона + короткая фраза. Без "скачай", без значков.

### 3. RuStore большой баннер: `out/rustore-banner-1280x720.png` (+ `.jpg`/`.webp` версия)

1280x720, **не больше 150 КБ** (ужми в WebP или JPG, проверь размер). Верхние 10% пустые
от ключевых элементов. Главный объект по центру. Текст 20-30% площади, крупный.
**Название приложения на баннере не писать** - RuStore показывает его сам.
Фон контрастный: не должен сливаться ни со светлым, ни с тёмным интерфейсом магазина.

## Как делать

- Каждый макет - HTML/CSS (`layouts/*.html`), рендер в PNG через headless Chrome:
  `"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new --disable-gpu --hide-scrollbars --force-device-scale-factor=1 --window-size=W,H --screenshot=OUT file://...`
  или Playwright из `~/Library/Caches/ms-playwright`. Python с PIL доступен для обрезки, проверки
  размеров и снятия альфы; `cwebp` есть.
- После рендера сам посмотри каждую картинку и исправь: обрезанный текст, наезды, мелкий
  нечитаемый текст, пустые углы, разный стиль кадров.
- В конце: `out/contact-sheet.png` - все 6 скриншотов в ряд для обзора, и `out/README.md`
  с размерами и весом каждого файла.
- Скрипт рендера: `render.sh` или `render.py` - чтобы всё пересобиралось одной командой.
